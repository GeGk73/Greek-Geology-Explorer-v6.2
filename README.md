# 🗺 Greek Geology Explorer — v6.0

Εφαρμογή πεδίου για τις γεωτεκτονικές ζώνες της Ελλάδας. Λειτουργεί ως PWA
(εγκαθίσταται σε Android & iOS) και **δουλεύει εξ ολοκλήρου offline**.

## Αρχεία

| Αρχείο | Περιεχόμενο |
|---|---|
| `index.html` | Η εφαρμογή — βάση ζωνών, ανίχνευση, ιστορικό, βιβλιοθήκη |
| `petro_summaries.js` | Οι πετρολογικές συνόψεις (18 ζώνες/ενότητες) |
| `manifest.json` | PWA manifest |
| `sw.js` | Service Worker (offline cache v6.0) |
| `icons/` | Εικονίδια 192 & 512 px |

## Λειτουργίες

**📍 Εντοπισμός** — GPS ή χειροκίνητες συντεταγμένες → ανιχνεύει τη ζώνη,
δείχνει λιθολογία / ηλικία / τεκτονική / χρήσεις ανά ενότητα, και την
πετρολογική σύνοψη.

**📚 Βιβλιοθήκη** — και οι 18 συνόψεις σε αναπτυσσόμενη λίστα, χωρίς GPS.

**📋 Ιστορικό** — αποθήκευση θέσης με ημερομηνία, ζώνη, ενότητα και
προαιρετική σημείωση. Μένει τοπικά στη συσκευή (localStorage).

## Deploy σε GitHub Pages

1. Δημιουργία **public** repository στο github.com
2. Upload **όλων** των αρχείων (μαζί με τον φάκελο `icons`)
3. Settings → Pages → Deploy from branch → `main` / `(root)` → Save
4. Μετά από 1-2 λεπτά: `https://<username>.github.io/<repo>/`

HTTPS είναι απαραίτητο για GPS και Service Worker — το GitHub Pages το
παρέχει αυτόματα.

## Εγκατάσταση στο κινητό

- **Android / Chrome** — μπάνερ «Προσθήκη στην αρχική οθόνη», ή μενού ⋮
- **iOS / Safari** — κουμπί κοινοποίησης □↑ → «Προσθήκη στην αρχική οθόνη»

## Ενημέρωση περιεχομένου

Για νέο ή διορθωμένο κείμενο ζώνης αρκεί να αλλάξει το `petro_summaries.js`.
Μετά από κάθε αλλαγή, ανέβασε τον νέο αριθμό έκδοσης στο `CACHE_NAME` του
`sw.js` ώστε να ανανεωθεί το offline cache στις συσκευές.
